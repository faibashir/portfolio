# Faisal Bashir — EDA Portfolio Site

A responsive static portfolio website for showcasing electronics design and simulation skills.

## Tools highlighted

- KiCad
- LTspice
- Ngspice
- Qucs-S
- DesignSpark
- LibrePCB
- Python-assisted simulation automation

## How to customize

1. Replace the sample project descriptions in `index.html` with your real projects.
2. Replace `mailto:`, LinkedIn, and GitHub links with your preferred links.
3. Add real sample files, screenshots, Gerbers, BOMs, reports, or PDFs to an `assets/projects` folder.
4. Deploy on GitHub Pages, Netlify, Vercel, or any static web host.

## GitHub Pages deployment

1. Create a new GitHub repository, for example `eda-portfolio`.
2. Upload these files to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from branch**.
5. Choose branch `main` and folder `/root`.
6. Your portfolio will be published as a GitHub Pages URL.

## Important

Before submitting this as a work-sample link, make sure the listed projects and experience statements match work you can explain and support with actual files or screenshots.
